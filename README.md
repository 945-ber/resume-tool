# 简历智能改写工具

一个本地运行的网页应用：上传简历（任意格式）→ 上传目标公司 JD/要求（任意格式，包括图片）→ 自动完成 **本地识别 → 匹配分析 → 公司官网与痛点情报 → 生成 1 份岗位完全定制版简历**。

核心目标只有一个：**让简历完全贴合目标岗位，帮用户进入面试**，而不是做一堆花哨版本。

## 快速启动

**本机使用（推荐）**：双击桌面「**简历智造启动器**」快捷方式（或项目里的 `启动器.pyw`）→ 图形化界面自动拉起服务，显示：
- 本地服务状态（http://127.0.0.1:8000）
- **局域网直连地址 + 二维码**（手机连同一 WiFi 扫码即开，最稳最快）
- **公网隧道网址**（一键复制；手机流量/异地使用，个别运营商可能打不开 → 用局域网）

- `一键启动.bat`：最简入口，检测服务已跑时直接打开浏览器。
- 服务已绑定 `0.0.0.0` 并放行防火墙 8000 端口 → 同一局域网手机/平板可直接访问。
- 手机访问：优先「局域网直连」（同一 WiFi 扫码）；公网隧道为临时免费，关闭后地址失效。

## 使用步骤（4 步递进，可自由切换）

1. **我的简历**：粘贴简历全文，或拖拽/上传文件自动识别（Word / PDF / 图片 / TXT）。
2. **公司要求**：粘贴公司要求/JD，或拖拽/上传文件（Word / PDF / **图片自动识别**）；公司名、岗位名自动提取回填，无需自己查官网（官网地址由系统自动查询）。
3. **AI 分析与情报**：匹配分析（评分/差距/隐藏优势）+ 公司官网四维情报（业务方向/招聘信号/企业状态/正规性）。
4. **定制成品**：唯一主成品「岗位完全定制版」——完全围绕该 JD 重写（模块按岗位相关度重排、JD 关键词同频、真实优势显性化）。**不满意？点「重新生成」再出一版**，直到满意。
5. **导出三件套**：成品区可一键导出 `Word 版` / `PDF 版` / `图片版`，或 `📦 三件套打包`（zip 一次全拿），排版为 A4 专业简历样式，全程 0 token。图片/PDF 简历的照片可单独上传含照片的 Word 简历来嵌入。

## 公司情报（中小厂也覆盖）

- 系统自动查官网：公司名 → 搜索 → 官网域名自动发现（如任子行 → https://www.1218.com.cn）。
- 多源采集：搜狗（主引擎，串行防封）＋ Bing/百度（副引擎）＋ 招聘平台（BOSS直聘/猎聘）＋ 官网/新闻交叉验证。
- 输出：企业现状、正规性评估、招聘信号、业务方向、公司痛点、简历表述方向、面试可能问的问题。
- **在招岗位画像**：无官网/信息少的小公司（如 0-20 人的律所），系统会从招聘平台聚合该公司**其他在招职位**，由 AI 分析"这家公司到底需要什么样的人、是否真的在扩张招人"。
- **口碑与用人状态**：从脉脉/看准/职友集等口碑源聚合员工评价，判断是否值得投、投递风险点；无口碑则如实说明，不硬编。
- 搜不到公开痕迹的公司（只在登录墙内）会明确标注「未查到可靠佐证」，不硬编。

## 成本设计（好钢用在刀刃上）

| 阶段 | 是否消耗 token | 说明 |
|---|---|---|
| 简历/JD 文字识别 | **0** | 纯文本本地直读；图片用**本地 OCR**（RapidOCR，离线，零 token） |
| 公司/岗位自动提取 | **≈0** | 本地规则优先 + 结果缓存，规则判不出才调 AI |
| 匹配分析 | 消耗 | 深度贴岗的核心，不省 |
| 公司情报采集 | 部分消耗 | 官网/新闻抓取为本地爬取（0 token）；仅"综合成建议"用 AI |
| 成品改写 | 消耗 | **只有 1 份主版本**（不再 3 版重复生成）；不满意可重新生成 |

- 顶栏「⚡ AI 用量」实时显示今日消耗；点击可打开**用量仪表**：账户实时余额、累计 token、折算金额、分阶段消耗占比、最近调用明细。
- 每次 AI 调用明细自动写入 `data/usage.csv`（时间/模型/阶段/输入输出 token），随时可查账。
- **已禁用 DeepSeek 模型推理模式（thinking disabled）**：deepseek-flash 默认会"思考"，大量 token 耗在推理上且响应极慢（曾 21.8s 才返回且内容为空）。禁用后：单次请求 0.9s、token 消耗大降（reasoning 不再计费），识别/分析/改写全部恢复稳定。**这是成本与速度的关键优化。**

## 技术栈

- 后端：Python 3.12 + FastAPI + SQLite（`backend/`）
- 前端：Vue 3 + Element Plus 单页应用（`frontend/index.html`，库文件已本地化，离线可用）
- 本地 OCR：RapidOCR（onnxruntime，CPU 离线识别，0 token）
- AI：DeepSeek API（`resume-tool/.env` 中配置 Key 与模型）

## 配置

编辑 `resume-tool/.env`：

```
DEEPSEEK_API_KEY=你的Key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash   # 或 deepseek-v4-pro
```

## 数据存放

- 上传文件：`data/uploads/`
- 导出的 Word：`data/exports/`
- 任务与版本记录：`data/resume_tool.db`
- AI 用量明细：`data/usage.csv`

## 后端 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/upload | 上传简历，返回 task_id 与解析文本 |
| POST | /api/parse_document | 解析任意文档/图片（kind=resume\|jd，本地 OCR 优先） |
| POST | /api/extract_meta | 自动提取公司/岗位（本地规则优先+缓存） |
| POST | /api/generate | 一键：分析+情报+1 份岗位完全定制版 |
| POST | /api/regenerate | 不满意时重新生成主版本（不重跑分析/情报） |
| GET | /api/usage | AI 用量汇总（分阶段+明细） |
| GET | /api/balance | DeepSeek 账户实时余额 |
| GET | /api/export/{version_id} | 导出成品：?format=docx\|pdf\|png\|zip（三件套打包） |
